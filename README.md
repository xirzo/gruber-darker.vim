# gruber-darker.vim
*gruber-darker* is a low-contrast, warm dark color theme used by [rexim](https://github.com/rexim), also known as [Tsoding](https://www.youtube.com/tsoding)

## Installation

Add this to your *.vimrc*

```vim
call plug#begin()
" other plugins

Plug 'xirzo/gruber-darker.vim'

call plug#end()
```

Run *PlugInstall* command and set the colorscheme

```vim
colorscheme gruber-darker
```
